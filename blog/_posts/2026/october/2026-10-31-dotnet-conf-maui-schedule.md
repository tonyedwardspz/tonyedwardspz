# Your MAUI schedule for .NET Conf 2026

[.NET Conf](https://www.dotnetconf.net/) is just around the corner!

Taking place online between the 10th and 13th November, the four-day event brings together speakers from across the globe to share what's new in .NET, best practices, and a few tips and tricks from the people building and using the technology every day.

With .NET 11 launching during the event, there's plenty to look forward to, including some significant changes to .NET MAUI.

You can find the full agenda on the [official website](https://dotnet.microsoft.com/en-us/conf/2026/agenda). But what if you're not interested in trawling through dozens of sessions to find the good stuff? The MAUI magic!

Well, you're in luck! I've pulled together the .NET MAUI sessions, along with a few that should be particularly interesting to cross-platform C# developers.

Of course, there's plenty more worth watching. Performance optimisation, C# improvements, Aspire, AI, developer tooling and a whole bunch of other topics. So don't forget to have a look through the full agenda yourself.

All times below are **UK time (GMT)**.

## Tuesday 10th November

### 19:30 – What's New in .NET MAUI in .NET 11

**Speaker:** [Gerald Versluis](https://www.linkedin.com/in/jfversluis/)

The big one! Gerald takes us through the changes coming with .NET MAUI 11.

This year's release introduces some significant improvements, including the move to CoreCLR, XAML source generation being enabled by default, C# expressions in XAML and incremental Hot Reload. We'll also get a look at Material 3 styling on Android, improvements to testing and the wider developer experience.

There's quite a lot happening under the hood this year, so this should be a good starting point for anyone looking to move their applications to .NET 11.

## Wednesday 11th November

### 00:30 – Bringing dotnet run, test, and watch to .NET MAUI

**Speaker:** [Jonathan Peppers](https://www.linkedin.com/in/jonathanpeppers/)

One of the more interesting developments in .NET 11 is the work being done to bring MAUI closer to the standard .NET CLI experience.

Jonathan will demonstrate how `dotnet run`, `dotnet test` and `dotnet watch` can be used with Android and iOS applications, covering everything from device selection to running tests and updating applications. 

For those of us working with VS Code, automated builds or AI coding agents, this could make a real difference. Anything that reduces our dependence on IDE-specific tooling is a welcome improvement.

### 21:30 – Beyond Code Generation: Give AI Eyes and Hands for .NET MAUI

**Speaker:** [Gerald Versluis](https://www.linkedin.com/in/jfversluis/)

AI is getting pretty good at generating code, but knowing whether that code actually works is another matter.

Gerald explores how DevFlow, GitHub Copilot and an interactive mobile canvas can be used to interact with a running MAUI application.

We'll see how an AI assistant can inspect controls, access logs, interact with the application and replay workflows to check that changes have worked.

It's an interesting step towards bringing AI into the full development and testing workflow, rather than simply generating XAML and C#.

## Thursday 12th November – Community Day

The community programme also includes a session focused on the less glamorous, but arguably more important, side of building mobile applications.

### Your .NET MAUI App Works. Now Give It to a Real User.

**Speaker:** [Paul Usher](https://www.linkedin.com/in/paulusher/)

Getting an application running on your own device is one thing. Getting it to behave when real people start using it is something else entirely.

This session looks at the challenges of building production applications, including unreliable connectivity, large datasets, hardware differences and offline workflows.

It's a topic that deserves more attention. There's a considerable difference between a demo application and something people depend on every day.

*Check the official agenda for the confirmed start time.*

## Friday 13th November – Community Day

### 16:00 – One Codebase, Two Worlds: Sharing Razor Components Across Blazor Web and .NET MAUI Hybrid

**Speaker:** [Shriram Sankaran](https://www.linkedin.com/in/shriram-sankaran/)

Blazor Hybrid offers an interesting alternative to building every interface in XAML.

Shriram will explore sharing Razor components, services and application logic between web applications and native .NET MAUI applications. For teams already working with Blazor, it's an opportunity to see how existing skills and components can be reused across platforms.

### 16:30 – Building an AI-Powered Community Platform with Blazor, .NET MAUI, Aspire, and Azure AI Foundry

**Speaker:** [Augustine Correa](https://www.linkedin.com/in/augustine-correa-b0a72117/)

This session brings together quite a few pieces of the modern .NET ecosystem.

Augustine explores the architecture of a community platform built using Blazor, .NET MAUI, Aspire and Azure AI Foundry. I'm always interested in seeing how these technologies fit together in an actual application, rather than being demonstrated independently.

## What am I looking forward to?

There's a good mixture of framework improvements and practical development tooling this year.

The move to CoreCLR is a particularly interesting development, as is the ongoing work to simplify XAML development.

I'm also keen to see what Jonathan Peppers has to show us around the CLI. Making MAUI applications easier to build, run and test without relying on a particular IDE opens up quite a few possibilities.

And, of course, it's good to see the community contributing sessions that focus on actually building and maintaining applications.

.NET Conf is completely free, so there's no excuse not to catch a few sessions. And if the timings don't work for you, recordings should be available afterwards.
